# 구조 설명

## 화면과 라우팅

해시 라우팅을 쓰기 때문에 서버 설정 없이 한 파일로 동작합니다.

| 주소 | 화면 | 함수 |
|---|---|---|
| `#/` | 질문 검색 (최근 등록 12건) | `viewSearch()` |
| `#/q/<검색어>` | 검색 결과 | `viewSearch(q)` |
| `#/faq/<id>` | 답변 상세 + 같은 분류 질문 | `viewDetail(id)` |
| `#/admin` | 로그인 전에는 로그인, 로그인 후에는 답변 관리 | `viewLogin()` / `viewAdmin()` |

답변 관리 화면은 위에서부터 단건 등록, 질문 수정 + 등록된 질문 목록, 구글 시트 연동, 일괄 등록, 관리자 계정 순서입니다.

## claude.ai 런타임 기능

`window.claude.use(이름)`으로 가져오며, 쓸 수 없는 환경에서는 `null`이 돌아옵니다.

| 기능 | 용도 |
|---|---|
| `db` | 질문, 시트 설정, 관리자 계정 저장 (실시간 구독 `onSnapshot`) |
| `assets` | 답변 이미지 업로드. 편집자만 사용할 수 있고, `/_blob/<id>`로 표시합니다. |
| `mcp` | Google Sheets 커넥터의 `get_values` 호출. 보는 사람의 Google 권한으로 동작합니다. |
| `downloads` | 일괄 등록 양식(xlsx) 다운로드 |
| `user` | `canEdit()`으로 편집 권한 확인. 자동 동기화 실행 조건에 씁니다. |

선언 내용은 `artifact.capabilities.json`에 있습니다.

## 데이터 구조

### `faqs/<id>`: 질문 1건

```json
{
  "category": "프로그램",
  "question": "최신버전 프로그램 다운받고싶어요",
  "answer": "아래 링크에서 다운받으면돼요 ...",
  "keywords": ["다운로드", "설치"],
  "images": [{ "id": "<asset id>", "name": "설치화면.png" }],
  "updatedAt": 1790920000000
}
```

- 문서 id는 단건 등록이면 자동 생성, 구글 시트에서 온 질문이면 `sheet-<질문 해시>`입니다. 그래서 같은 질문을 다시 불러오면 새로 만들지 않고 갱신합니다.
- 질문이 같은지는 공백을 빼고 대소문자를 무시해서 비교합니다.
- 저장 한도는 5,000건으로 잡아 두었습니다.

### `settings/sheet`: 구글 시트 연동 설정

```json
{ "url": "", "sheetName": "", "colQ": "C", "colA": "E", "colC": "F",
  "skipHeader": true, "auto": false, "lastSyncAt": 0, "lastResult": "" }
```

### `data/admins/accounts/<아이디>`: 관리자 계정

```json
{ "salt": "<base64>", "hash": "<base64>", "iter": 150000,
  "createdAt": 0, "createdBy": "", "lastLoginAt": 0, "pwChangedAt": 0 }
```

## 로그인 흐름

1. 아이디로 계정 문서를 읽습니다. 편집 권한이 없으면 문서가 "없음"으로 보입니다.
2. 입력한 비밀번호를 같은 솔트와 반복 횟수로 PBKDF2 처리한 뒤 저장된 해시와 비교합니다. 비교는 시간 차이가 나지 않는 방식으로 합니다.
3. 성공하면 `sessionStorage`에 `{id, exp}`를 저장합니다. 탭 단위로 8시간 유지되고, 탭을 닫으면 사라집니다.
4. 관리자 목록을 실시간으로 구독합니다. 내 계정이 목록에서 사라지면 **문서를 직접 다시 읽어 확인한 뒤에만** 로그아웃합니다. 첫 스냅샷이 빈 캐시로 오는 경우를 오판하지 않기 위해서입니다.
5. `crypto.subtle`이 없거나 실패하면 같은 알고리즘의 JS 구현(`pbkdf2js`)으로 계산합니다.

## 구글 시트 연동 흐름

1. 열 설정에서 범위를 만듭니다. 예: `A1:F`, 탭 이름이 있으면 `'탭'!A1:F`
2. `mcp.describeTool`로 커넥터 입력 스키마를 확인한 뒤 `get_values`를 호출합니다.
3. 응답에서 2차원 `values` 배열을 찾고, 분류 열이 빈 행은 제외합니다.
4. 일괄 등록과 같은 미리보기 화면으로 넘깁니다. 상태는 새로 추가 / 갱신 / 변경 없음 / 중복 / 오류로 표시됩니다.
5. 자동 동기화: 편집자가 로그인한 상태에서 페이지를 열고, 마지막 동기화 후 30분이 지났으면 새 질문과 바뀐 답변만 반영합니다. 시트에서 지운 행은 사이트에서 지우지 않습니다.

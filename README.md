# CS 문의 답변센터

고객 문의에 대한 답변을 검색하고 관리하는 웹페이지입니다.
**claude.ai 아티팩트**로 운영 중이며, 페이지 전체가 `src/index.html` 파일 하나에 들어 있습니다.

- **질문 검색** (누구나): 단어 일부나 초성(예: `ㅂㅁㅂㅎ`)으로 검색하고, 자동완성과 분류 필터를 지원합니다.
- **답변 관리** (관리자 로그인): 질문 등록·수정·삭제, 이미지 첨부, 엑셀 일괄 등록, 구글 시트 연동, 관리자 계정 관리

> ⚠️ 이 파일만 다른 서버에 올리면 **동작하지 않습니다.** 데이터 저장, 이미지, 구글 시트 읽기, 권한 확인을 모두 claude.ai 런타임(`window.claude`)에 맡기고 있기 때문입니다. 독립 배포 방법은 [docs/migration.md](docs/migration.md)를 보세요.

## 폴더 구조

```
.
├── src/index.html               # 앱 전체 (HTML + CSS + JS, 빌드 과정 없음)
├── artifact.capabilities.json   # 아티팩트에 선언한 런타임 기능과 DB 접근 규칙
├── tools/make-admin-hash.mjs    # 관리자 계정 문서 생성기 (비밀번호 → 해시)
├── tests/
│   ├── mock-runtime.js          # window.claude 를 흉내 내는 테스트용 목
│   └── run.mjs                  # 관리자 로그인 흐름 테스트 (Playwright)
└── docs/
    ├── architecture.md          # 화면 구성, 데이터 구조, 권한, 구글 시트 연동
    └── migration.md             # claude.ai 밖으로 옮길 때 바꿔야 할 것
```

## 주요 기능

| 영역 | 내용 |
|---|---|
| 검색 | 부분 일치 + 초성 검색, 키워드·답변 본문 가중치 검색, ↑↓/Enter 자동완성, 분류 필터 |
| 답변 표시 | 빈 줄 → 문단, `1.` → 단계 목록, `-` → 글머리표, `` `코드` ``, `[이미지:파일명]` 자리에 이미지 삽입, 클릭하면 크게 보기 |
| 단건 등록·수정 | 분류(기본: 프로그램/설정/오류, 직접 추가 가능), 질문, 키워드, 답변, 이미지(붙여넣기·끌어 놓기) |
| 일괄 등록 | xlsx/csv 업로드 또는 엑셀 붙여넣기, 미리보기 후 "추가·갱신" 또는 "전체 교체", 양식 다운로드 |
| 구글 시트 연동 | 질문·답변·분류 열 지정(기본 C/E/F), 분류가 채워진 행만 가져오기, 30분 간격 자동 동기화(선택) |
| 관리자 | 아이디/비밀번호 로그인(탭당 8시간 유지), 관리자 추가·삭제, 비밀번호 변경 |

## 운영 (claude.ai 아티팩트)

### 수정본 반영하기

`src/index.html`을 고친 뒤, Claude에게 기존 아티팩트 URL로 다시 게시해 달라고 요청하면 됩니다. URL과 저장된 데이터는 그대로 유지됩니다.
기능 선언(`artifact.capabilities.json`)을 바꿀 때는 게시할 때 그 내용도 함께 넘겨야 합니다.

### 관리자 계정

- 계정은 아티팩트 DB의 `data/admins/accounts/<아이디>` 문서에 저장됩니다. 비밀번호는 **PBKDF2-SHA256 해시(15만 회, 솔트 16바이트)로만 저장**되고, 평문은 어디에도 남지 않습니다.
- 계정 문서는 아티팩트 **편집자(Editor) 이상만** 읽고 쓸 수 있도록 규칙을 걸어 두었습니다. 일반 방문자는 계정 문서를 읽을 수 없습니다.
- 첫 관리자 계정은 아래처럼 만든 값을 Claude에게 DB에 넣어 달라고 하면 됩니다. 이후 관리자는 화면의 "관리자 계정" 칸에서 추가하면 됩니다.

  ```bash
  npm run admin-hash -- <아이디> <비밀번호>
  ```

- **관리자를 새로 추가하면, 그 사람을 claude.ai 공유 메뉴에서 편집자(Editor)로도 초대해야 합니다.** 실제 저장 권한은 claude.ai 권한이 결정하고, 로그인은 그 위에 하나 더 건 잠금입니다.

### 구글 시트 연동

1. claude.ai **설정 → 커넥터**에서 Google Sheets를 연결합니다. 이때 Google 권한 화면의 체크박스를 **전부 체크**해야 합니다. 빠뜨리면 `Insufficient scope` 오류가 납니다.
2. 답변 관리 → 구글 시트 연동에 시트 주소를 넣고 열(질문/답변/분류)을 지정한 뒤 [지금 불러와서 미리보기]를 누릅니다.
3. 시트는 **불러오는 사람의** Google 계정 권한으로 읽습니다.

## 테스트

```bash
npm install
npx playwright install chromium
npm test
```

`tests/run.mjs`는 테스트 전용 계정을 즉석에서 만들어, 실제 런타임 대신 목으로 다음을 확인합니다.

- 정상 로그인
- 브라우저 암호 기능(WebCrypto)이 없을 때 JS 대체 구현으로 로그인
- 비밀번호 틀림 (A2)
- 없는 아이디 (A1)
- 한글 입력 상태
- 로그인 직후 빈 목록이 먼저 와도 로그아웃되지 않는지, 새로고침 후에도 로그인이 유지되는지

## 로그인 오류 코드

| 코드 | 뜻 |
|---|---|
| A1 | 아이디를 찾지 못함. 등록되지 않았거나, 편집 권한이 없는 claude.ai 계정으로 연 경우 |
| A2 | 비밀번호 불일치 |
| A3 | 암호 확인 기능을 쓸 수 없음 (현재는 JS 대체 구현이 있어 거의 발생하지 않음) |
| A4 | 기타 오류. 괄호 안에 원인 코드가 표시됨 |
| A5 | 예상하지 못한 오류 |

## 보안 메모

- 저장소에 **비밀번호, 해시 값, 실제 시트 데이터를 커밋하지 마세요.** `.gitignore`에 `*.seed.json`과 `admin_seed*.json`을 넣어 두었습니다.
- 로그인 확인은 브라우저에서 이뤄집니다. 따라서 실제 보안 경계는 claude.ai의 편집 권한입니다. 독립 서버로 옮길 때는 서버 측 인증으로 바꿔야 합니다([docs/migration.md](docs/migration.md) 참고).
